# 🦷 Dental Clinic Website

A modern and responsive dental clinic website built with **React** and **Vite**, featuring a clean and professional user interface designed to provide a simple and pleasant experience for visitors.

## ✨ Features

* 📱 Fully responsive design
* 🦷 Dental clinic services section
* 👩‍⚕️ About the clinic section
* 💬 Customer testimonials
* 📝 Appointment booking interface
* 💡 Dental health tips
* ✨ Smooth animations and transitions
* 🎨 Modern and clean UI

## 🛠️ Technologies

* React
* JavaScript
* Vite
* Tailwind CSS
* Framer Motion
* Lucide React
* React Icons

## 🚀 Installation

Clone the repository:

```bash
git clone https://m-reyhaneh-m.github.io/dental-clinic-react/
```

Go to the project directory:

```bash
cd dental-clinic-react
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite in your browser.

## 📦 Build

To create a production build:

```bash
npm run build
```

The production files will be generated in the `dist` folder.
